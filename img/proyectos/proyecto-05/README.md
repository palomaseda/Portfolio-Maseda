# Fotos del proyecto 05

- `cover.jpg` → la portada (la foto grande de la sección).
- `01.jpg`, `02.jpg`, `03.jpg`… → la galería, en ese orden.

Lo que haya en esta carpeta es lo que muestra la galería: para sacar una foto,
borrala; para agregar, sumá el número siguiente. Si quedan huecos (01, 02, 05)
no se rompe nada.

Ideal: fotos verticales 3:4 (1350 × 1800 px). Las versiones reducidas
(`-thumb`, `-gallery`) se generan aparte.
